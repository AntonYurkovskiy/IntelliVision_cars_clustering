# Описание кластеров

> Ссылки: [итоговый отчёт с метриками](final_report.md) · [пошаговый ноутбук](../project_6_clustering.ipynb) · [аналитический ноутбук](../notebooks/03_analysis.ipynb)

В проекте выделены две лучшие конфигурации на дескрипторе `vdc_type` с KMeans и 5 кластерами:
- **Лучшая по Calinski-Harabasz:** `vdc_type / minmax / KMeans / 5` (CH 107 466, DB 1,81).
- **Лучшая по Davies-Bouldin:** `vdc_type / standard / KMeans / 5` (CH 94 664, DB 1,62).

Описание ниже относится к конфигурации со **стандартизацией** (лучшая по DB). Семантика кластеров для конфигурации с **MinMax** схожа, поскольку обе используют один и тот же дескриптор `vdc_type`; различия касаются размера и компактности кластеров. Визуальные примеры для обеих конфигураций сохранены в [`figures/`](figures/).

## Лучшая по Davies-Bouldin: vdc_type, стандартизация, KMeans, 5 кластеров

| Кластер | Описание |
|---------|----------|
| 4 | Седаны, вид сзади. Везде видны задние фары. |
| 3 | Микроавтобусы, в основном светлого цвета. Все фото — вид спереди, кроме одного сзади. |
| 2 | Седаны, вид спереди. Везде видны передние фары. |
| 1 | Каблучки, хэтчбеки и минивены. Вертикальный срез сзади и наклонный срез спереди. |
| 0 | В основном большие джипы. Единичный грузовик и один хэтчбек затесались. |

## Лучшая по Calinski-Harabasz: vdc_type, MinMax, KMeans, 5 кластеров

Эта конфигурация даёт наибольшее межкластерное расстояние (CH 107 466). Кластеры сохраняют ту же тематику — седаны спереди/сзади, джипы, хэтчбеки/минивены, микроавтобусы — но оптимизированы под максимальное разделение, а не под минимальную внутрикластерную дисперсию. Для детального визуального сравнения см. [`figures/images_vdc_type_minmax_kmeans_cluster*.png`](figures/).

## Сводная интерпретация

Дескриптор `vdc_type` (частично обучен на исходном датасете для классификации типа ТС) в сочетании с KMeans даёт наиболее интерпретируемые кластеры. Основные разделения:
- по типу кузова (седан, хэтчбек, джип, микроавтобус);
- по ракурсу (спереди / сзади);
- частично по цвету (светлые микроавтобусы).

Выбор между `standard` и `minmax` зависит от цели: `standard` — для компактности и чистоты кластеров (лучший DB), `minmax` — для максимального разделения между кластерами (лучший CH).

## Наблюдения по выбросам

### Isolation Forest (1% доля выбросов)

- Все автомобили **белого цвета**.
- Преобладают **грузовые / угловатые прямоугольные формы**:
  - грузовики с морскими контейнерами;
  - старые грузовые бусики с маленькими задними фарами и квадратными окнами;
  - маленькие грузовики с открытым кузовом.
- Одна легковушка — трёхдверный хэтчбэк старого дизайна с необычными фарами.
- Одно фото частично заслонено веткой.
- **Итог:** выбросы в основном — редкие в датасете типы ТС с угловатыми формами и белым цветом.

### Local Outlier Factor (1% доля выбросов)

- Все автомобили **не белого цвета**, преимущественно **тёмные**.
- Одно фото сделано в **тёмное время суток**.
- На двух фото присутствует **ветка дерева**, частично заслоняющая автомобиль.
- **Итог:** LOF выделяет аномальные условия съёмки (ночь, заслонение, нестандартный цвет).

### Вывод по выбросам

Разные алгоритмы находят разные типы аномалий:
- **Isolation Forest** — редкие классы объектов (грузовики, старые дизайны);
- **LOF** — аномалии условий съёмки (ночь, заслонение, тёмный цвет).
